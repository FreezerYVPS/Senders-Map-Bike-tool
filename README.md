Replaces one of the game's models with your own .blend. $5 to whoever models and imports the moist critikal moby huge pitbike into the game and sends me the file first

Needed:
  Blender, and Python 3 for Windows from python.org (then double-click the .pyw).

HOW TO USE THIS BS:
 Useage for bike imports:
select the .blend of the bike you wish to import
select the .blend of the bikeyou are replacing
click the edit model button in the bottom left tab and align the foot pegs and handle bars up with
the pegs and bars of the original bike     
click export, then bring the file to  \Senders Playtest\content\meshes and overwrite the original file, usually the tool will make a file with the original bike under a file extension .orig, just delete that extension and use that file if you need to go back to the original bike
for now, textures are written into the png that usually goes on the bikes bar pad, models also have no normal maps, i dont have access to anything but the bar pad at the moment

Useage for map imports:
click the map editor button in the bottom left corner
<img width="1001" height="912" alt="image" src="https://github.com/user-attachments/assets/56e0f4b0-9a95-494a-b13a-244a029561f9" />
here you can create an area, and use a combination of the jumps tool and the sculpt tools to make a track of your own by dragging things in place
alternatively, you can import finished heightmaps, or the tool can even pull a heightmap from a .pkz file from mx bikes, THIS WILL ONLY WORK ON MXB TRACKS THAT HAVE NOT BEEN ENCRYPTED BY INLOCK, WHICH IS A MAJORITY OF THEM
when importing an mxb map, give the tool the pkz, a window will open, click import in that window
<img width="1509" height="951" alt="image" src="https://github.com/user-attachments/assets/2ff4a9f9-815b-49a7-b180-c20482998b26" />
itll bring the heightmap on top of the original game map, drag it around to your desired location, then click the confirm selection button on the right, this will place the map down and clear anything that was sitting in that maps area from the base game map.
<img width="1519" height="950" alt="image" src="https://github.com/user-attachments/assets/bfddea56-7566-4460-a4ab-2c9c456b21dc" />
select a surface type for the map, for now you're going to be using track 2 dirt about 90% of the time <img width="1515" height="946" alt="image" src="https://github.com/user-attachments/assets/8e884173-9f02-4feb-b67e-bbf5923561f9" />
click save as, and save the map to your downloads
<img width="2557" height="1432" alt="image" src="https://github.com/user-attachments/assets/a391b1e6-4203-4df0-98e5-251d8297500e" />
Once the map has been saved, click the install a saved map button, which will install the map to the game, if this does not work, instead simply drag the map file from your downloads into the same meshes folder from the bike instructions earlier, same as last time, make a copy of the original
